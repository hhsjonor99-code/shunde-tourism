## 一、产品定位

### 1.1 核心定位
**顺德城市旅游数字名片 + 主题路线展示 + 本地规则个性化推荐**

不是全国旅游规划工具，也不是"填写出发地和目的地生成 Markdown 攻略"的通用产品。

### 1.2 目标用户
1. 第一次来顺德的游客；
2. 广州 / 佛山 / 深圳周边一日游、周末游客；
3. 喜欢顺德美食、岭南园林、水乡古村、历史文化、城市夜景的人；
4. 不同同行组合：独自、情侣、朋友、带孩子、带父母。

### 1.3 用户核心需求
1. **快速建立顺德第一印象**：水乡、园林、寻味、烟火四张水墨主题图；
2. **挑选契合的主题路线**：5 条预制主题路线（R1-R5）+ 2 条半天变体（H1、H2）；
3. **根据自身条件生成行程**：天数、同行人、兴趣、交通、节奏 + 自由文本；
4. **获得真实可信的距离/时间/地址信息**：基于 MCP 核验（2026-07-18）；
5. **直观看到行程结构**：水墨长卷 + 印章节点 + 时间轴。

### 1.4 核心文案
- 主标题：一卷顺德
- 副标题：水乡入画，寻味成诗
- 欢迎文案：一方水土，十镇烟火。沿着园林、水乡与美食，展开一卷顺德生活。
- 主按钮：展开顺德 / 为我画一卷行程

## 三、5 条主路线（R1-R5）+ 2 条半天变体（H1、H2）

### 3.1 总里程 / 总交通时间范围（强制）
所有路线的 `totalDistance` 和 `totalTransportTime` **只统计相邻景点之间的已核验路段**，**不包括**：
- 用户出发地 → 首站；
- 末站 → 返程地；
- 住宿接驳；
- 候车 / 停车 / 步行至公交站时间；
- 景区内部游览时间。

> "以下里程与时间为相邻景点之间的实测数据，不含出发地接驳、住宿、候车、停车和景区内部游览时间。"

### 3.3 路线详情

#### R1 初见顺德 · 大良经典一日游

- 适合：第一次来顺德、独自/情侣/朋友
- 节奏：经典适中

#### R2 水乡慢游 · 逢简寻味一日
- 顺序：逢简水乡 → 清晖园 → 华盖路 → 金榜上街

- 适合：喜欢慢游、摄影、亲子
- 节奏：悠闲

#### R3 园林烟火 · 顺德文化一日游
- 顺序：顺峰山公园 → 顺德博物馆 → 清晖园 → 华盖路 → 金榜上街
- 路段：驾车 3862m → 驾车 7739m → 步行 585m → 步行 833m
- 适合：带父母、亲子
- 注意：顺德博物馆周一闭馆

#### R4 艺术与夜色 · 顺德城市一日游
- 顺序：和美术馆 → 欢乐海岸PLUS → 容桂渔人码头

- 适合：情侣、朋友、艺术爱好者

#### R5 两日寻味顺德

## 四、推荐引擎确定性评分规则

### 4.1 候选池
7 条预定义路线：`R1, R2, R3, R4, R5, H1, H2`。

### 4.2 第一步：按天数硬过滤
| 用户选择天数 | 候选 |
|------------|------|
| `half-day` | 仅 `H1, H2` |
| `one-day`  | 仅 `R1, R2, R3, R4` |
| `two-day`  | 仅 `R5` |

### 4.3 第二步：硬排除
- 选择"公共交通" + 候选含跨镇街段（北滘/容桂/逢简等）→ **直接排除**。
- 首版实际可保留公共交通友好路线：`H1, H2, R1, R3`。

### 4.4 第三步：评分
| 维度 | 分值 |
|------|------|
| 兴趣每匹配一项 | +5 |
| 同行人匹配 | +4 |
| 交通方式匹配 | +4 |
| 节奏匹配 | +3 |
| 关键词命中 | 按 `KeywordRule.weight` 加分 |
| 带父母 + 路线总步行 > 1.5 km | -6 |

### 4.5 同分排序
1. 兴趣匹配数更多者优先；
2. 总里程更短者优先；
3. 路线 ID 字典序优先。

### 4.6 路线 5 Day 1+Day 2 评分
- 用户选 `two-day` 时，唯一候选为 R5；不存在评分；直接返回 R5 的 Day 1 + Day 2。

### 4.7 自定义出发地处理
- 第一版**仅作备注**，不参与距离、时间和路线计算；
- 推荐算法中按 `in-shunde` 处理（视为已抵达顺德本地）；
- 表单提示固定文案：

> "第一版不会查询自定义地址的位置，建议选择已核验车站或'已到达顺德'。"

- 结果页**不展示**自定义地点接驳距离或时间。

## 六、公共交通功能边界

### 6.1 第一版明确不实现
- 不展示公交线路、班次、换乘方案；
- 不显示精确公共交通时间；
- 不调用 `maps_direction_transit_integrated`；
- 不展示实时公交。

### 6.2 选择"公共交通"时的处理
- 推荐引擎只推荐地点集中、公共交通相对友好的路线；
- 结果页底部固定提示：

> "根据地点集中程度推荐，未核验具体公交线路。本路线未含精确公交信息，请在出发前通过高德地图 APP 或网页实时查询。"

### 6.3 展示规则
- 自驾：显示高德驾车时间；
- 打车：显示"驾车路线参考时间，不含候车"；
- 公共交通：不展示驾车总时间，显示"暂无精确公交耗时"；
- **严禁**把驾车时间当成公交时间。
